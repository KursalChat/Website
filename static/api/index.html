Want to try these interactively?

This page is reference-only. Kursal serves a runnable copy of these docs that executes requests against your own instance.

  1. In Kursal, open Settings › Advanced › Local API Server and enable it.
  2. Restart Kursal for the change to take effect.
  3. Visit http://127.0.0.1:4892

Disabled by default. Port 4892 unless you changed it.
